## Honeycomb

Honeycombing is the standard way of creating a buffer to delay the attackers from reaching the castle heart. It is done by creating as much 1x1 rooms as possible between the plot's entrance and the castle heart. All rooms should be surrounded by doors to allow defenders to navigate easily. Same with entrance designs, it's best to use double-hinged see-through doors.

This is only for the ground level of the castle. If you want a buffer for the higher floors, do a [snake maze](snake-maze.md) instead.
